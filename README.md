# TG MADAD — обновления программы

Здесь лежат только файлы обновлений программы TG MADAD (Qoldau Center).

- Во вкладке **Releases** — архив `tg-madad-app-<версия>.zip` и его контрольная сумма `.sha256`.
- Программа сама проверяет новую версию раз в 10 дней (или по кнопке «Проверить сейчас»),
  скачивает, проверяет контрольную сумму и ставит ночью или по кнопке «Обновить сейчас».
- Клиентов, переписок и номеров клиентов здесь нет.

В программе: «Аккаунты» → «Обновления программы» → адрес `mmtlovesh-tech/tg-madad`.
